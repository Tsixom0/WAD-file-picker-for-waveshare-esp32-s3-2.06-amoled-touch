# WAD-file-picker-for-waveshare-esp32-s3-2.06-amoled-touch
A touch-friendly WAD launcher for DoomWatch that automatically scans the SD card for IWADs and PWADs, displays file information, manages per-WAD save directories, and launches DOOM directly from the watch interface.
